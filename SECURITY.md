## Reporting a Vulnerability

If you discover a security vulnerability within this repository or any associated playbooks, please **do not** open a public issue.

Instead, please report the vulnerability privately by sending an email or contacting the repository maintainers directly.

### What to Include in Your Report

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue (including any example playbooks or configurations).
- Suggested fix or mitigation, if known.

We will acknowledge receipt of your report and provide status updates on resolution.
